# FUNCIONALIDADES PRINCIPAIS

## 1. Bloco de Notas Inteligente

O usuário deve poder:

- criar notas
- editar notas
- arquivar notas
- favoritar notas
- pesquisar notas
- fixar notas

Visual:

- estilo post-it moderno
- visual limpo
- sem poluição

Animações:

- nota sendo "fixada" com clipe de papel
- leve efeito de empilhamento
- hover elegante

---

## 2. Quadro de Projetos

O usuário deve poder:

- criar projetos
- criar listas
- criar tarefas
- arrastar tarefas

Modelo:

Backlog
Em andamento
Aguardando
Concluído

Drag and Drop obrigatório.

---

## 3. Fluxogramas

O usuário deve poder:

- criar fluxos simples
- conectar etapas
- mover blocos

Exemplos:

- Processo de autorização
- Processo financeiro
- Fluxo de atendimento
- Fluxo operacional

Não quero complexidade nível BPM.

Quero simplicidade semelhante ao Excalidraw ou Miro básico.

---

## 4. Área de Conhecimento Pessoal

Permitir:

- armazenar procedimentos
- checklists
- documentos rápidos
- aprendizados

Formato:

Cards organizados por categoria.

---

## 5. Compartilhamento

Por padrão:

Tudo privado.

O usuário pode:

- compartilhar projeto
- compartilhar nota
- compartilhar fluxo

Permissões:

VIEW
COMMENT
EDIT

Implementar modelo semelhante ao Google Docs.
